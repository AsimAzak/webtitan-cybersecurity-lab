# WebTitan Cybersecurity Lab

This repository contains my educational lab for analyzing and testing web filtering with **WebTitan Cloud**.  
The goal is to understand **SSL interception, DNS filtering, and potential bypass methods** in a controlled environment.

## 🔹 Lab Objectives
- Identify how WebTitan filters web traffic
- Test common penetration testing techniques for bypassing web filters
- Document findings with network captures and flow diagrams

## 🔹 Contents
- `lab-report.md` – Detailed step-by-step test report
- `screenshots/` – Proof of block pages, certificate checks, and packet captures
- `network-diagram.png` – Visual representation of WebTitan interception
